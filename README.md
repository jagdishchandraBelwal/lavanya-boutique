# Lavanya | Multi Designer Store (Meerut)

React website for @lavanyatheboutiqueindia  
Inspired by modern Indian ethnic e-commerce UI (festive cream / maroon / gold).

## Run
```bash
npm install
npm run dev
```

## Deploy
Push to GitHub → Import on Vercel.
